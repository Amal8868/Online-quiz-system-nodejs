# Online Quiz System - Frontend (React.js)

A modern, responsive frontend built with React.js and Tailwind CSS, designed for high-stakes online examinations.

## ✨ Features
- **Dynamic Dashboards**: Custom interfaces for Admins, Teachers, and Students.
- **Real-time Monitoring**: Teacher dashboard to track student progress during active exams.
- **Secure Exam Mode**: Fullscreen-ready interface with auto-submission on timer expiry.
- **Theme Support**: Fully integrated Dark/Light mode.

## 🛠️ Tech Stack
- **React.js**: Functional components and Hooks.
- **Tailwind CSS**: Utility-first styling with custom purple theme.
- **Framer Motion**: Smooth micro-animations.
- **Axios**: API communication with JWT interceptors.

## 🚀 Getting Started

1. **Navigate to the frontend directory**:
   ```bash
   cd frontend-nodejs
   ```

2. **Install dependencies**:
   ```bash
   npm install
   ```

3. **Start the development server**:
   ```bash
   npm start
   ```

## 🛡️ Role-Based Access
| Role | Capabilities |
| :--- | :--- |
| **Admin** | Manage users, manage classes, view system reports. |
| **Teacher** | Create quizzes, monitor sessions, grade answers. |
| **Student** | Join exams via code, attempt quizzes, view scores. |
